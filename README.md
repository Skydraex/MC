# Sky Prison

A classic-style Minecraft prison server, built as a single Paper plugin. Mine, sell, rank up
A through Z. Everything — the world, the hub, all 26 mines, the cell block, the grounds — is
generated by the plugin on first boot. You never place a block or run a setup command.

## What you need

- **Paper** (Minecraft 1.21.x or newer; the build targets Java 25)
- **Vault** — the economy bridge the plugin talks to
- **An economy plugin** — EssentialsX is the usual choice. Vault is only a bridge; without
  an actual economy provider behind it the plugin will not enable.

Nothing else is required. A live server should also run an anti-cheat, CoreProtect and a
backup schedule, and NuVotifier if you want votes to award keys — none of those are part of
this plugin and all are installed the normal way.

## Install

1. Download `PrisonPlugin.jar` from the latest green run on the **Actions** tab (click the
   run → **Artifacts** → **PrisonPlugin**).
2. Start Paper once so it makes its folders, then stop it.
3. Put Vault, EssentialsX and `PrisonPlugin.jar` in `/plugins`.
4. Start the server.

The first boot builds roughly 1.1 million blocks — the whole prison, the mine level and the
countryside around it. Expect it to take a little while and say so in the console. Every
boot after that is instant.

**To rebuild the world from scratch:** stop the server, delete the `prison` world folder,
start it again. That is sufficient on its own — the plugin checks the world actually exists
rather than trusting a marker file.

## The map

The hub is a 136×136 walled compound on a plateau, ringed by a cliff and a flooded moat.
Its perimeter carries **gates only**, which is what keeps it small enough to cross quickly.

- Each mine gate opens through a short corridor into a ward.
- The ward has a stair down to the mine level and a cage lift, which goes straight there.
- The stair leads to a 160-block shaft out to a **ring concourse** that all 26 mines open off.
  You can walk between mines underground without coming back up.
- Mines are open pits in lit caverns, each with a landscaped plot, planted terraces and its
  own theme.

Also in the hub: the cell block (108 cells on six galleries around an atrium), the canteen,
the workout yard, the commissary, the enchanter, the crate hall, the Yard (PvP) and the jail.
Outside it: the fishing ponds, the logging yard and the farm, around a shared green.

## Staff ranks

Five rungs, each inheriting the one below. Grant them with your permissions plugin.

| Permission | Rank | Can do |
|---|---|---|
| `prison.staff.helper` | Helper | `check`, `warn`, `staff` |
| `prison.staff.mod` | Moderator | + `mute`, `unmute`, `kick`, `jail`, `unjail` |
| `prison.staff.admin` | Admin | + `setrank`, `fishlevel`, `resetplayer`, `validate` |
| `prison.staff.superadmin` | Super Admin | + `givekey`, `givegear`, `givemoney` |
| `prison.staff.owner` | Owner | + `rebuild` |

**Anything that puts an item or a balance into a player's hands is Super Admin or above**,
deliberately. It is the one kind of staff abuse that cannot be undone, because the items are
spent or traded before anyone notices.

`/padmin` lists only what your own rank can run. The legacy `prison.admin` node still works
and maps to Admin. Every staff action against another player is logged with who did it.

## Player commands

`/help` opens a categorised menu of everything below.

- `/rank`, `/rankup`, `/ranks` — the ladder
- `/warps`, `/mine <letter>` — getting about
- `/sell`, `/shop`, `/autosell` — the money loop
- `/cell claim|home|renew|info|unclaim` — renting a cell
- `/enchant` — pickaxe upgrades, at the enchanter in the middle of the hub
- `/fishing`, `/sellfish` — the ponds
- `/prestige` — once you reach Free
- `/rules`, `/vote`

## Design rules this server sticks to

It is a **classic** prison server, not an OP one. Concretely, that means:

- **One currency.** Dollars. No tokens, gems or shards.
- **Ordinary enchants.** Efficiency, Fortune, Unbreaking, Haste. No Explosive, no Auto-Smelt
  — an enchant that clears a 3×3×3 per swing, or smelts for you, deletes the
  carry-it-back-and-sell-it half of the loop the whole game is built on.
- **The loop is physical.** Mines are walked to. Selling happens at a sell point. The
  enchanter is a place in the hub, not a command you type from inside your cell.
- **Crates are modest.** Four rungs, the same odds wherever an item appears, and the best
  non-jackpot piece is roughly what vanilla enchanting can already produce.
  `CrateData.audit()` enforces that at startup.

## For developers

The map's geometry is **generated, not hand-written**:

- `tools/layout_gen.py` is the single source of truth for every rectangle.
- `tools/map_check.py` validates it — shared-edge widths, doorway routes, reachability —
  and CI runs it before the build.
- `tools/gen_java.py` bakes it into `MapLayout.java` and `RankMineData.java`.
  **Those two files are generated. Never edit them by hand.**

After changing the layout: `cd tools && python3 gen_java.py && python3 map_check.py`.

Openings between areas are derived from the validated layout and cut in one pass after the
build, rather than by whichever method built each wall. That is not a style choice — hand-
carved doorways sealed every ward, then the fishing lobby, then the grounds, on three
separate occasions, and nothing caught it because the world looked finished either way.
